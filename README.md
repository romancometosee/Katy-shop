# Katy — магазин парфюмерии и косметики

Интернет-магазин на Next.js: витрина с каталогом и админка, где можно без программиста добавлять товары, менять цены, запускать акции и баннеры.

## Что есть

**Витрина**
- Главная: баннеры-слайдер, преимущества, разделы, хиты, акции с таймером, новинки, подбор аромата, ароматы по нотам, бренды, отзывы
- Каталог: разделы и подразделы (Парфюмерия, Уход за лицом, Макияж, Волосы, Тело, Подарочные наборы), фильтры по цене, бренду, «для кого», семейству аромата, сортировка
- Бренды А–Я и страница каждого бренда
- Карточка товара: объёмы с разными ценами, ноты аромата, отзывы (с модерацией), похожие товары
- Поиск по названию, бренду и нотам («ваниль», «роза»…)
- Подбор аромата — тест из 4 вопросов
- Избранное, корзина, промокоды, оформление заказа, подарок в каждом заказе
- Адаптивная вёрстка под телефоны

**Админка** — `/admin`
- Обзор: заказы, выручка, отзывы на проверке, товары, которые заканчиваются
- Товары: добавление и редактирование, фото, объёмы и цены, быстрая смена цен и остатков прямо в списке, массовое изменение цен на % по бренду или разделу
- Акции (скидка на раздел, бренд или отдельные товары на время) и промокоды
- Баннеры на главной, разделы каталога, бренды, заказы со статусами, настройки магазина

## Запуск

```bash
npm install
cp .env.example .env.local   # и поменяйте пароль
npm run dev                  # http://localhost:3000, админка — http://localhost:3000/admin
```

Пароль админки по умолчанию — `katy2026` (меняется в `ADMIN_PASSWORD`).

## Данные

Сейчас данные хранятся в файле `data/db.json` (создаётся из демо-каталога при первом запуске), загруженные фото — в `data/uploads/`.
Всё чтение и запись идут через `src/lib/db.ts`, поэтому для боевого сайта его можно заменить на базу данных, не трогая страницы.

Для хостинга нужен сервер с постоянным диском (VPS, Render, Railway и т. п.) — на Vercel файловое хранилище не сохраняется, там нужна база данных.

Картинки товаров в демо-каталоге — нарисованные иллюстрации флаконов. Когда в админке у товара появляется фото, показывается оно.
